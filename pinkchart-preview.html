Atualização diária e semanal

Os dados iniciais mostram a data da última medição confirmada. O coletor incluso atualiza streams de músicas e álbuns no Kworb, charts diários e semanais; ouvintes dependem da disponibilidade da fonte e seguidores exigem credenciais válidas da API do Spotify.

Para o agendamento funcionar, publique a pasta do projeto no GitHub e ative o GitHub Actions/Pages. Em caso de falha, o site mantém o último valor verificado em vez de estimar streams.

Somas entre artistas podem duplicar colaborações; por isso o filtro “Todos” não soma métricas de perfis diferentes. Totais de álbuns mostrados pelo Kworb podem diferir da soma das faixas listadas.

PINKCHART é um projeto de fã, sem vínculo oficial com Spotify, BLACKPINK ou gravadoras.
